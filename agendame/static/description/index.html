Agendame - Appointment Booking

Let visitors book appointments on your website. Availability is computed from your team's real calendars.

www.vicbas.com

Key Features

Public Booking Page

A /agendame page on your website where visitors pick a meeting type and an available time slot.

Real Availability

Slots are generated from per-weekday time windows and each staff member's existing calendar events — no double bookings.

Automatic Contacts

The visitor becomes a contact: name, email, phone, tax ID and country are created or updated on every booking.

Videocall Ready

Each appointment type can set its videocall source (Discuss, Google Meet, Zoom) on the created meeting.

CRM Integration

Assign an appointment type to any opportunity and share its booking link with one click.

Record-Level Security

Internal users manage only their own agendas and cannot book on behalf of others. Admins keep full control.

How It Works

  • 1. Configure appointment types under Calendar → Appointments: duration, timezone, staff users, weekday availability, colors and cover image.
  • 2. Share the public booking URL with your customers.
  • 3. Visitors book: they fill in their details and pick a free slot; availability adapts to each staff member's calendar.
  • 4. Odoo creates the calendar event with attendees, videocall source and booking status — plus the contact record.

Out of the Box

  • Every internal user gets a default agenda (Mon–Sat, 10:00–18:00, own timezone) on install and on user creation.
  • Appointment menus integrate into the native Calendar app — no separate application.
  • Booking status tracking on each meeting: requested, booked, attended, no-show, cancelled.
  • Client tax ID (RUT/VAT) and country stored on the meeting for Latam-ready workflows.

Requirements

  • Odoo Community or Enterprise with Website, CRM, Calendar and Mail installed
  • No Enterprise Appointments module required — this addon is fully independent
