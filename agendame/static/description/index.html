Agendame — Appointment Booking

Online appointment booking for Odoo Community

Agendame adds a public booking page to your Odoo website. Visitors pick an appointment type and a free time slot, and Odoo creates the calendar event and the contact. Free slots come from each staff member's real calendar.

Features

What it does

Public booking page

An /agendame page on your website where visitors choose a meeting type and an available slot.

Real availability

Slots are built from per-weekday time windows and each staff member's existing events, with conflict detection.

Automatic contacts

Name, email, phone, tax ID and country are created or updated on the visitor's contact on every booking.

Standard calendar events

Each booking is a regular Odoo event with attendees, reminders and videocall support.

CRM integration

Assign an appointment type to an opportunity and share its booking link in one click.

Record-level security

Internal users manage only their own agendas. Administrators keep full control.

Getting started

How it works

1
Install
Requires Website, CRM, Calendar and Mail. Every internal user gets a default agenda (Mon–Sat, 10:00–18:00, own timezone).
2
Configure appointment types
In Calendar → Appointments, set the duration, timezone, staff, weekday windows, color and cover image.
3
Share the link
Publish the booking URL, or send it from a CRM opportunity.
4
Visitors book
They fill in their details and pick a free slot. Availability follows each staff member's calendar.
5
Track the meeting
Booking status on each event: requested, booked, attended, no-show or cancelled.
