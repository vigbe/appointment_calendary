What it does

Public booking page

A /agendame page on your website where each staff member's agenda is listed. Visitors pick an agenda, a day and an available time slot — no login required.

Real availability

Slots come from each agenda's per-weekday time windows and are filtered against the staff's real Odoo calendars: already-busy times simply never appear.

Events created for you

On confirmation Odoo creates the calendar.event with the visitor as attendee, plus/updates the matching contact — your agenda fills itself.

How to use it

Five minutes from install to first booking:

  1. Install the module
    From Apps (developer mode not required). Depends on Website, CRM and Calendar — all Community.
  2. Every internal user gets a default agenda
    On install (and on user creation) each internal user receives an agenda Agenda de <user> with Mon–Sat 10:00–18:00 availability and 1-hour meetings.
  3. Tune each agenda
    Open the agenda (search Tipos de Cita) and adjust meeting duration, per-weekday time windows, timezone and the public page colors.
  4. Share the booking link
    Send visitors to /agendame, or use the booking link button on a CRM lead to offer that contact a meeting with the salesperson.
  5. Visitor books → Odoo records
    The visitor picks a free slot and leaves name + email (phone/country optional). The event lands on the staff calendar and the lead/chat gets updated.
